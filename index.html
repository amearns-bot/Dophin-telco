Facilitator script — map clicks to talk track

Step 1 · Dead Click
Click "Have a referral code? Apply it here." It does nothing — that's the trap. In Digital Assist this logs as a Dead Click. Talk track: "Traditional analytics wouldn't flag this at all — the user didn't bounce, didn't error out. Qualtrics catches the moment intent silently failed."
Step 2 · Second Dead Click
Click "Why do we need this?" — same trap, different page. Use it to show Page Tags grouping step-1/step-2/step-3 into one "SIM Activation Funnel" report instead of three separate raw URLs.
Step 3 · Rage Click
Click "Complete activation" rapidly, 4+ times, in quick succession. The button intentionally stalls for ~1.2s on first load to invite exactly that pattern. This is the Rage Click signal (4+ clicks, <200px apart, <300ms apart). Pivot here to the Digital Opportunities Widget and Frustration Targeting Logic — "this is the moment we'd trigger an empathetic intercept or route to a support team with full session context attached."
Bonus dead-click zone
The top nav (Home/TV/Broadband/Mobile/Deals/search) is decorative and also no-ops — real global nav often behaves this way in production too when links aren't wired to real routes. Useful as an "in the wild, this happens more than people think" aside if it comes up naturally.
Tag Manager (bottom-left button)
Open the teal Tags panel and edit the JSON live — e.g. add "dealStage":"POC" — then hit Apply. Talk track: "This is exactly what your existing tag manager would hand Qualtrics — a plain JSON object. On our side, an intercept just points an Embedded Data field at window.getDolphinTag('dealStage') and it's instantly available for targeting, personalization, or reporting. No redeploy needed to add a new field."
Deployment story
Point to the page <head> source: GTM container placeholder + commented Qualtrics Project Deployment Code inside it, plus the Tag Manager engine that feeds embedded data to both Qualtrics and dataLayer. Talk track: "This loads asynchronously through your existing tag manager — no page slowdown, no new IT deployment for every intercept or embedded-data change afterward."
Before the real session
Fill in window.DOLPHIN_CONFIG and paste the real Qualtrics Project Deployment Code (from Directory > project > Project Deployment) in place of the placeholder. Re-verify the CSP nonce property name and the "Value from JavaScript" embedded-data behavior against current Qualtrics docs before sharing any code with the customer's dev lead. Restyle the :root variables and plan names if reskinning for a specific opportunity.
